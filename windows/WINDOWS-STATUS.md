# PDF Master V0.1.5 Windows preview1

Windows 专用独立适配，不改 Mac 源码和安装。此预览不是已完成的 Mac 无损对等版，不能用相同版本数字推断功能一致。

实现范围：本地 PDF 打开/只读密码查看、PDF.js 渲染、查找、翻页/缩放；标准矩形/椭圆/区域高亮/手绘与便笺批注，删除批注；撤销/重做；页面旋转、复制、删除、重排、提取；合并、PNG/JPEG 转 PDF、PNG 导出、页码；随包qpdf结构压缩（不重编码图片，不保证缩小，变大则保留原字节）、AES-256打开密码另存副本；原生选择/拖入、另存为和未保存退出提示；在线无限画布的独立隔离窗口。所有保存使用同目录临时文件后原子替换，不自动修改源PDF。密码仅经进程标准输入传递，不写入命令行或日志。

未完成的 Mac 能力：完整原文内容编辑、OCR、AI和本机账户、完整无边记格式互通、工具图标皮肤/收藏/最近、批注外观互操作与正常速度GUI人审。界面明确显示适配中，不能将这些条目写成通过。自由文字未嵌入字体时拒绝，不静默输出乱码。密码保护仅为AES-256另存副本；权限编辑、加密文档继续编辑及全部密码互操作未验收。

安全/数据限制：256MB/10000页以内；重写引擎拒绝数字签名/部分主动操作文档；页面结构重写明确拒绝含目录、文档级表单、附件命名树、标记结构或图层配置的文件，避免静默丢失信息。检测并不覆盖所有PDF扩展；预览须用文档副本并另存，不覆盖唯一原件。Windows安装/更新/卸载、跨端全部文件往返仍待人审。无代码签名，无SmartScreen信誉保证，不要求关闭系统保护。

依赖：Electron（MIT及随包Chromium通知）、Mozilla PDF.js（Apache-2.0）、pdf-lib（MIT）、qpdf 12.4.2（Apache-2.0及完整上游Windows归档内的依赖许可）；保留各包许可证。未打包Apple Framework或第三方专有软件代码，未引入新的AGPL PDF引擎。原创源码权利条件沿用仓库COPYRIGHT.md。
