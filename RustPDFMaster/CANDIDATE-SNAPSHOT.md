Physical iOS, Windows runtime, signing, notarization, App Store and complete product acceptance remain pending.

iOS export now moves only an application-generated disposable staged copy, never the user's source PDF. It obtains the system destination's security scope and uses NSFileCoordinator on a worker thread to read the actual coordinated target under a 32 MiB budget. Cancellation, denied access, failed coordination, mismatched bytes or failed durable checkpoint do not clear the unsaved state. Local iOS simulator tests verified a new 919-byte target and a same-name Keep Both 922-byte target, exact current PDF bytes, clean checkpoints, unchanged source/previous-target hashes, and reopening the second target with intact Unicode note contents.
