# Candidate source snapshot — not a product release

2026-10-26. Additive Rust migration source imported from development revision `2386c608346f0b4fd1533e8d82509e3468d5ecdc` using an explicit 113 tracked-file allowlist (`RustPDFMaster/` and this candidate workflow only). This note is the additional snapshot manifest. Existing native product source, installer, version tags and Releases are not replaced by this snapshot. No private development history, drafts, personal PDFs, credentials, generated project, build cache or screenshots are included.

The Rust core and UI are intentionally incomplete. Full parity is not approved. Current locally exercised foundation: 102 core tests (including 17 notes contracts), 24 UI tests, 40 native-shell tests plus 3 security contracts; 28 tools contracts including CI/artifact, notices and inventory. The 801 original XCTest traceability entries remain pending, not passing Rust contracts. This snapshot adds bounded Unicode text search/result navigation, range rotate/delete with one undo, native snapshot-bound confirmation for all page deletion, adjacent page moves, readable mobile input controls and bounded Text-note creation/current-page read-only lists. A bounded core UpdateNote API binds the original annotation index and expected contents, copies shared annotations on write and validates post-edit count/content budgets; there is no note-editing UI yet. Updates are not secure erasure: old indirect objects may remain serialized. Actual local Mac and iOS simulator tests cover move selection and cancellation; affirmative deletion remains unit-tested, not a GUI acceptance claim. Mac note creation/undo/redo/export/reopen was exercised using synthetic Unicode/emoji/script-literal content, with an independent exported-PDF check showing no JavaScript. iOS note creation/undo/redo was exercised with a public URL literal; planned Unicode keyboard input forwarding did not succeed. A separate imported synthetic Unicode note was rotated, exported, read back byte-for-byte and reopened on iOS. Physical iOS, Windows runtime, signing, notarization, App Store and complete product acceptance remain pending.

iOS export now moves only an application-generated disposable staged copy, never the user's source PDF. It obtains the system destination's security scope and uses NSFileCoordinator on a worker thread to read the actual coordinated target under a 32 MiB budget. Cancellation, denied access, failed coordination, mismatched bytes or failed durable checkpoint do not clear the unsaved state. Local iOS simulator tests verified a new 919-byte target and a same-name Keep Both 922-byte target, exact current PDF bytes, clean checkpoints, unchanged source/previous-target hashes, and reopening the second target with intact Unicode note contents. This does not certify iCloud/remote providers, physical devices, bounded provider I/O latency or the new move flow's GUI cancellation path.

That run does not certify this newer source. Validation rejects extra directory entries as well as unsafe HTML, credentials and paths. Local Mac and iOS archive notice bytes match generated sources. MPL obligations, NOTICE/source-material review, non-Cargo assets and legal clearance remain open; generated inventories are not legal certification.
