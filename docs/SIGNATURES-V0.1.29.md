# V0.1.29 / build51：PNG 图形签名

> 历史本地候选记录，未作为独立版本公开发行。签名面板及创建流程已由V0.1.30修正；当前使用方法以[新版说明](SIGNATURES-V0.1.30.md)为准，旧版独立窗口/立即入库/删除确认不再适用。

## 使用

进入“填写和签名 → 签名”或“编辑 → 图形签名…”，打开“我的签名”。

- “导入 PNG…”：选择本机 PNG，保留透明度和图像比例；成功导入后自动加入本机历史。
- 点击历史预览，再在 PDF 上点击放置，或拖框等比放入框内。按 Esc 取消当前放置。
- 手绘入口保留；一次多笔手绘是一枚签名批注，可整体撤销。
- 历史项的删除操作需要确认，仅删除签名库副本，不删除原始 PNG，也不影响已经签入并保存的 PDF。
- 添加签名后仍需正常保存 PDF；签名历史保存与 PDF 保存是两件事。

签名库仅在本机应用支持目录保存，同一正式版的标签和窗口共享；验证包与正式版隔离。不会上传签名图片。相同规范化 PNG 去重，重启后历史仍可复用。

## 限制与安全边界

仅支持单帧 PNG，最多8MiB、4,000,000像素；历史最多100项、图片合计128MiB。达到限额报错，不自动删除旧签名。不自动去白底，不提供云同步。损坏索引或图片会提示，拒绝静默覆盖已有历史。

图片作为自包含的 PDF Stamp 批注保存，包含透明度外观，不依赖原图片路径或签名库文件。遵循 PDF 批注权限及现有撤销、保存保护。签名库删除不是 PDF 内容撤回；已经发送给他人的文件不会随之变化。

这是图形签名，不是数字证书签名；不验证签署人身份，不提供可信时间戳或法律效力保证。通用“印章”、电子公章和验章不在本版范围。导入的第三方文件仍应先用副本验证。

本轮依据已有入口观察和自有实现完成；原版签署入口受试用提示限制，未绕过，不能宣称原版完整动态逆向或逐像素一致。
