使用教程 / 从第一份文档开始

把 PDF 用起来，
一步一步来。

首次安装：不需要开发环境，也不关闭全局保护

适用于 Apple 芯片、macOS 14 或更新版本。当前 V0.1.24 / build46 是未获 Apple 公证的开发预览；这不是 App Store 审核或安全认证。运行未经公证的软件有风险，是否信任由你自己决定。

  1. 从本网站下载区进入 GitHub Release，取得 PDFMaster-V0.1.24-arm64.dmg，不要使用不明镜像或他人重打包的副本。软件免费，安装时不要求购买会员、安装 Python 或填写 AI Key。
  2. 可选核对下载：在 macOS 自带“终端”输入 shasum -a 256 （末尾留一个空格），把刚下载的 DMG 拖入终端再按回车。结果应与下方完整值一致；不一致就停止。校验只证明与公开包字节一致，不证明没有恶意软件。
    V0.1.24 安装包 SHA-256

    61c68466a70b395cca2df153d1f70d22284aa25c3f97434925a84ba5459b7962

  3. 保存已有文档并正常退出旧版。打开 DMG，把 PDF Master.app 拖到“应用程序”；确认不会丢失自己的旧文档后再替换同名旧版。随后从“应用程序”打开 App，无需保留挂载的安装磁盘。
  4. 如提示开发者无法验证或 Apple 无法检查，先停下来阅读警告。仅在你确认是可信来源、未遭篡改，并接受风险时，按 Apple 官方说明，在刚尝试打开后进入“系统设置 → 隐私与安全性”，选择针对该 App 的“仍要打开”，再确认“打开”。这是一项单应用例外，不是关闭全局保护。
  5. 如果提示“已损坏”“将损坏”或恶意软件，或系统没有该按钮，不要强行放行，保留警告并反馈。受管理的 Mac 请联系系统管理员，不绕过组织限制。

验证范围：已在开发 Mac 验证自包含启动与自建 PDF 副本编辑、保存重开；另在 GitHub 两台干净的 Apple 芯片虚拟机（macOS 14.8.9、15.7.9）验证原样公开包启动、包内 qpdf 与正常退出，查看记录。两台安全评估均启用，但以 curl 下载，不代表浏览器隔离属性和首次信任流程已验收；尚未在另一台 Mac 的首次浏览器下载场景验收。上述流程依据 Apple 官方说明，不保证所有系统通过。未配置可选 AI 不影响本地阅读与批注。

01 / 开始：先认识三个工作区

  1. 先阅读首次安装与安全提示，完成安装并打开 App。未能安全完成时停止并反馈，不关闭系统全局保护。
  2. 主界面侧栏中，“工具”提供 PDF 工具卡片；“无边记”是本地资料画布；“无限画布”是内置节点工作区。两种画布不是同一个存档格式。
  3. 先选一份自己有权处理、不含敏感信息的 PDF。主界面点“打开文件”或拖入；菜单“文件 → 打开…”专用于 PDF。
  4. 立即用“文件 → 存储副本…”输出不同名称或位置的练习副本。存副本不会自动把当前标签切到副本：请关闭尚未修改的原件标签，重新打开刚存的副本，再开始练习。后续“保存”写入当前文档位置；不要在唯一原件上试验。

你会得到：一个练习副本的 PDF 工作台标签，可以继续阅读和批注。本地阅读不需要登录或 AI Key。未支持的工具卡片会禁用，不能靠反复点击解锁。

02 / 阅读、查找与书签

调整阅读布局

  1. 打开 PDF，用页码输入框跳转，或点侧栏缩略图。
  2. 在“显示”菜单选择“单页 / 双页 / 封面”相应布局；通过布局选项切换“连续滚动”。
  3. 选择“适合页面”“适合宽度”或实际大小，必要时放大检查小字。缩放只改变观看比例，不改变 PDF 内容。

拖动调宽左栏

把指针移到左栏右侧细分隔线上，出现左右调整光标后拖动；缩略图、目录、搜索、批注共用宽度。松手后记住宽度，隐藏再展开和重开应用均保留。方向键微调（Shift 加速），Home / End 到两端，Esc 取消未松手的拖动。常规范围 176–480 点，窄窗口或打开 AI 侧栏时会临时缩窄以保留阅读区，不改变保存的偏好。

查找一句话

  1. 按 ⌘F，在“搜索文档文字”中输入关键词。
  2. 点结果跳到所在页，⌘G 看下一项，⇧⌘G 看上一项；关键词太常见时缩小范围，结果有 1000 项上限。
  3. 无结果时先尝试选中文字。不能选择的扫描图像可能需要本地 OCR；受复制权限限制的文件不能靠 OCR 绕过权限。

添加导航与管理标签

  1. “大纲 → 查看与导航…”浏览已有目录；“为当前页添加顶层书签…”输入名称。
  2. 需要调整时使用大纲菜单中的重命名或删除顶层书签，随后保存 PDF。
  3. ⌘T 返回新标签主界面，⌘W 关闭当前标签。未保存的更改会提示保存、取消或放弃。

输出与边界：书签写入保存后的 PDF；最近和收藏只记录本机文件入口，不是备份。阅读兼容说明 →

03 / 批注：标记、写字与手绘

高亮、下划线、删除线

  1. 先拖选已有文字；扫描图片本身无法直接选择。
  2. 点“批注”工具条对应标记，或“编辑 → 高亮 / 下划线 / 删除线”。
  3. 完成后选择批注检查颜色与位置；不合适时按 ⌘Z 撤销。

文字批注、便笺与形状

  1. 选“文字批注”并在页面放置，输入内容；文字批注可移动、双击再编辑。
  2. 便笺用于附加简短备注；“批注”菜单提供矩形、椭圆、直线、箭头和双向箭头。
  3. 回到“选择批注”，点中对象后编辑或删除。侧栏“批注”可跳到对应页面、排序或复制摘要。

手绘与橡皮

  1. 选择“手绘”后拖动画笔，按属性栏调整支持的颜色、线宽。
  2. 橡皮点击删除一整条笔迹，不是局部擦除；误删可撤销。
  3. 按 Esc 退出当前放置 / 绘图操作，再保存或存储副本。

输出与边界：得到 PDF 批注，不会把正文改成 Word 文档。新增文字批注与原文编辑不同。批注支持范围 →

04 / 手写签名；印章当前不可用

  1. 进入“填写和签名 → 签名”，或“编辑 → 图形签名…”。
  2. 在“绘制图形签名”弹窗写下笔画，确认“插入”，再按页面放置提示操作。
  3. 检查大小、位置后保存副本；需要文字说明时用普通文字批注。

得到的是：手写图形，不是数字证书签名。它不验证身份，不包含可信时间戳，也不保证法律效力。

“印章”按钮目前禁用，没有可用的盖章教程；不支持电子公章、证书签章或验章。不要用图形签名代替授权公章。

05 / 原文文字、图像与链接

编辑原文，或者新增文字

  1. 工作台切换“编辑”，选“文本”。点击可识别原文会打开就地编辑；点击空白处则新建文字批注。
  2. 原文替换当前仅限单行。输入替换内容，按需选字体、字号、颜色，避免覆盖邻文；缺失字体可能被本机字体替代。
  3. ⌘↩ 完成，Esc 取消。若处理拒绝或邻文空间不足，草稿会保留，调整后再试。
  4. 检查原位置、搜索和复制结果，用“存储副本…”输出，再重新打开验证。

复杂字体、共享内容流、自定义编码、旋转裁剪或复杂页面结构可能不支持。失败时不要改用盖白块冒充原文替换。扫描页 OCR 后也不等于获得 Word 式段落编辑。

替换图像

  1. 选“编辑 → 图像”，点击可识别的原图。
  2. 选择本机 PNG 或 JPEG；共享原图及不支持的对象会拒绝。
  3. 检查裁切、比例和其他页面是否受影响，保存副本。

添加 / 更新 / 删除链接

  1. 选“编辑 → 链接”，拖出至少 8×8 点区域，填入目标地址并确认。
  2. 点击支持的已有链接，可修改地址，或选“删除链接”。
  3. 编辑时不会自动打开网址。导出后用可信阅读器核对区域及目标地址。

输出：支持对象的真实内容或链接被更新；不是仅更换屏幕显示。内容编辑完整边界 →

06 / 真正移除区域内容，务必检查副本

  1. 先保存原件备份。在“编辑 → 隐藏”或工具“隐藏 PDF 内容”中拖出至少 8×8 点区域。
  2. 阅读确认弹窗：区域文字以及相交图像、矢量对象可能被实际移除；相交对象可能整件删除，复杂结构会拒绝。
  3. 确认后检查页面其他位置。应用内撤销仍保留旧快照，不能把正在编辑的会话当作脱敏完成文件。
  4. 用“文件 → 存储副本…”生成独立文件，重新打开，并用其他可信工具复查敏感词搜索、复制、附件及元数据。

边界：这是有限结构重写，不是认证的全面脱敏。盖黑块、矩形批注或裁剪都不等于删除内容；不能只看页面表面。发现无法验证的结构时不要对外分享。了解隐藏功能限制 →

07 / 页面整理、合并与提取

  1. “页面 → 页面预览”（⌘4）进入总览，点击目标缩略图。按住 ⌘ 点选不连续页面，按住 Shift 选择连续范围；先检查高亮选中项，再操作。
  2. 用页面菜单顺时针 / 逆时针旋转、插入空白页、复制当前页、裁剪或移动当前页；总览支持的重排按界面拖动完成。
  3. 合并其他 PDF：选择“文件 → 附加文件并合并…”，选取来源后检查插入位置和页序。也可在主界面混合导入文件生成独立合并文档。
  4. 提取独立文件：“文件 → 提取页面…”，输入范围，例如 1-3,5，选择新位置。若提示移除原保护，先确认是否有权导出明文；不接受就取消。
  5. 删除页：“页面 → 删除页面…”，输入范围并确认。不能删除最后一页；误删可 ⌘Z 恢复。
  6. 保存副本，再检查页数、顺序、裁剪边界、书签和链接。

输出与边界：重排等操作修改当前工作区；提取是独立 PDF。裁剪只隐藏边界外内容，不是脱敏。页面管理选中缩略图后复制，切到目标 PDF 的页面管理选择插入位置再粘贴；保留原 PDF 页面。阅读区先按 Esc 清除批注选择、不要选中文字，再按 ⌘C 复制当前页；微信等图片接收端使用 PNG/TIFF，接收端实际兼容待实测。多页合成长图有像素上限，过长会整体降低清晰度。页面功能说明 →

08 / 图片、文字文件与混合导入

  1. 回主界面，点“打开文件”或拖入本机文件；支持 PDF、图片、TXT、MD、RTF 与纯文字 DOCX。单纯打开 PDF 也可用 ⌘O。
  2. 需要图片专用流程时，打开工具“图片转 PDF”。使用界面选取要转换的文件。
  3. 混合文件导入完成会生成新的独立 PDF，不修改来源。取消导入会丢弃本次结果。
  4. 检查图片方向、文字分页与合并顺序，选择保存位置。

边界：RTF / DOCX 仅按文字重新分页，不保留完整 Office 版式、图表和复杂对象；MD 不承诺按完整 Markdown 渲染。工具箱“Word 转 PDF / 表转 PDF / 其他文件转 PDF”仍未实现，不能把有限文字导入当成这些转换器。导入范围 →

09 / 导出图片、文字与批注摘要

按页导出 PNG / JPEG

  1. 打开 PDF 后进入工具“PDF 转图片”。
  2. 选格式、72 / 144 / 300 DPI，以及页码范围，例如 1-3,5。图片分辨率越高，输出越大。
  3. 点“选择位置并导出…”，使用新文件夹；不会覆盖已有文件夹。
  4. 核对导出页数与图像。图片是栅格文件，不保留可搜索文字及 PDF 对象。

文字、摘要与打印

  1. “文件 → 导出纯文本…”输出可提取的文字 TXT，版式不会保留。
  2. 需要批注汇总时，选择“导出批注摘要 TXT… / Markdown… / HTML…”；它不是整份 PDF 正文的导出。
  3. 纸质输出用“文件 → 打印…”（⌘P），在系统打印面板检查页数与缩放。

边界：文字导出遵守复制权限。扫描页、异常文字层或 OCR 兼容问题会影响结果。PDF 转 Word / Excel / PowerPoint 暂不支持。导出说明 →

10 / 压缩：先看实际结果，再存副本

  1. 选择“文件 → 压缩文件大小…”或工具“压缩 PDF”。
  2. 等待“更小文件 / 均衡压缩 / 高清晰度”逐档计算完成，比较实际大小；不要把“正在计算”当成结果。
  3. 不想降低画质时勾选“仅无损优化（不降低画质）”。已优化文档可能没有可缩小空间。
  4. 选择档位，点“另存为压缩副本…”，使用新位置。若计算期间编辑过文档，旧快照结果会失效，需要重新计算。
  5. 重开输出，重点放大检查扫描小字、图表、细线、图片和颜色，并核对页数及文字提取。

输出与边界：独立压缩 PDF，原件不覆盖。有损档会影响支持的图像质量和分辨率，不保证每份文件都能变小。压缩兼容说明 →

11 / OCR：让清晰扫描页可在本机查找

  1. 先确认扫描页方向正常、没有旋转或裁剪。打开“扫描和 OCR”或工具“识别文本”。
  2. 阅读“文字识别 · 简体中文 / 英文”提示，再点“开始”。处理在本机进行，不上传扫描页。
  3. 等待处理；已有文字的页面会跳过。取消会丢弃本次结果，不覆盖原件。
  4. 用 ⌘F 检索几个关键词，逐页核对人名、数字、标点；再存储副本。
  5. 若用于交付，请在接收方阅读器另测搜索和复制，不只检查本机。
通用文字提取兼容性尚未通过：保存后不能保证所有阅读器都能正确搜索复制。暂不支持旋转、裁剪页，也不承诺手写识别、表格重建或 OCR 后任意原文编辑。

12 / 为所有页面添加页码

  1. 进入工具“页码”。先检查文档有没有原有页码。
  2. 输入非负整数起始数字，可填前缀与后缀；默认页面底部，需顶部时勾选“放在页面顶部”。
  3. 点“开始”，检查首页、末页与正文是否重叠。
  4. 不满意可撤销；满意后存储副本。

输出与边界：所有页居中添加新页码；不会替换旧页码，只支持未旋转、未裁剪页面。

13 / 保存、打平、密码与撤销

  • 保存：⌘S 写到当前保存位置。首次保存或未命名文档会要求选择位置。
  • 另存为：“文件 → 另存为…”（⇧⌘S）选择新的工作文件。
  • 存储副本：输出独立文件，适合保留来源；不能用副本操作覆盖受保护来源。
  • 存储打平副本：固定批注外观。之后通常不能像原批注一样再编辑；保留未打平版本。
  • 存储密码保护副本：为新建或未加密来源设置密码，导出后重新打开测试密码。密码遗失没有恢复承诺。
  • 撤销 / 重做：⌘Z / ⇧⌘Z。它们不是长期备份，也不能撤回已发送的 AI 内容或远端任务。

已有加密 PDF 的原始底层权限无法可靠保留时，重新导出会拒绝，不自动退回明文。签名文档的内容重写有限制，不保证数字签名有效。原文件被其他软件修改时会提示冲突，优先另存为保留双方更改。

离开前：完成文字编辑，再保存。关标签或退出遇到未保存提示时选“保存”；不确定就“取消”。重新打开导出结果，才完成一次实际验收。保存边界 →

14 / 无边记：把 PDF 和想法放到一起

  1. 主界面侧栏“无边记 → 新建无边记”，或菜单“文件 → 新建无边记”。已有文件用“打开无边记…”。
  2. 用顶部“便笺 / 文本 / 矩形 / 圆形 / 连线 / 手绘”组织想法；“选择”移动对象，“手掌”平移。滚轮 / 双指滚动和捏合可缩放，Shift 或空格配合平移。
  3. 点“导入图片 / 导入 PDF”，或拖入本机文件。PDF 导入按页面嵌入独立副本；先核对页数和资源大小。
  4. 双击 PDF 卡片打开独立 PDF 标签。对该标签的编辑不会自动回写画布卡片或原文件。
  5. 点“保存”存为 .pdfmasterboard；“导出”可选 PDF 或 PNG。保留原画布文件，才能继续编辑对象。

输出与边界：.pdfmasterboard 是本地可编辑存档，PDF / PNG 是展示输出，不是云同步。AI创作可选且可能计费；离线整理不需要 Key。两种画布的区别 →

15 / 无限画布：节点工作区与 ZIP 备份

  1. 主界面侧栏选“无限画布”。这是 App 内置页面，基本编辑可离线，不用网站登录。
  2. 使用节点、文字、图片、连线、手绘、素材和提示词组织内容。详细控件说明可点上方“使用教程”，再用“返回画布”回到工作区。
  3. 本机存档自动保存在该 App 的 WebKit 存储。备份当前画布：点节点工作区左上角菜单图标，选择“导出当前画布”，保存 ZIP 到本机。
  4. 恢复备份：同一菜单选“我的画布”，进入“画布库”，点“导入画布”并选择 ZIP。不要把“导入资产”当作导入完整画布；也不要只导出选中素材代替整个画布备份。
  5. 不要随意点“清除本地数据”。旧网站项目不自动迁移；需要先从旧站导出，再导入。
  6. 要使用 AI 时，按下一节单独配置 Key，先以少量生成测试，再考虑批量任务。

格式提醒：无限画布 ZIP 与无边记 .pdfmasterboard 不相同，不能改扩展名互相替代。展示图、模板和示例素材不是实时生成结果；模型服务可用性需要实际账户验证。

16 / AI：设置、授权与费用

PDF Master 软件免费，不代表 AI 免费。第三方服务按各自规则收费，需你自己的 Key、模型权限和额度。本文不提供固定价格或免费额度承诺；不配置 Key 仍可使用本地阅读、批注和画布。

PDF Copilot：账户 Key 与文字问答

  1. 打开工具“PDF Copilot”，点“AI Key 设置…”。在本机账户界面创建自己的账户或登录；本机账户不是云端账号，也不赋予系统管理员权限。
  2. 为准备使用的 DMX / DeepSeek / Agnes 服务商保存对应 Key 到 macOS 钥匙串，不把 Key 填进文档或提示词。若使用初始默认账户，应先修改默认密码。
  3. 回 Copilot 选择服务商与允许的文本模型。保持默认“当前页”先测试；全文最多 4 万字，超限截断，不代表完整文档。
  4. 选择总结、提取要点、提问、解释、翻译、测验或批注摘要。核对发送范围，勾选允许发送文字及本轮对话，再点发送 / 生成。
  5. 将回答和引用逐一对照原文；需要时复制对话。“新对话”清空当前对话；切换文档、账户或服务商也会清空。

只发送范围内可复制文字和本轮对话，不发送 PDF 二进制或页面图片；受保护或限制复制的文件不提取发送。扫描页需先本地 OCR。Copilot 翻译是文字回答，不是保留版式的 PDF 翻译。停止请求不能撤回已发送内容，远端仍可能计费。

无限画布：独立 DMX Key，不需本机账户

  1. 在无限画布上方点“DMX Key 设置…”，填自己的 Key，选“保存到钥匙串”。此 Key 与本机账户 Key 独立，不自动迁移或共享。
  2. 在节点或生成面板填写提示词，选模型、尺寸与数量，先用 1 张图片测试。
  3. 首次发送时核对软件弹出的会话授权；只会发送提示词和所选参考素材，当前 PDF 不会自动上传。取消则不提交。
  4. 视频目前支持 Seedance 2.5 文生或单张首帧图；多参考图、尾帧、参考视频 / 音频暂不支持。提交后按任务 ID 查询，不自动重提。
  5. 刷新、改 Key 或退出后需重新授权。移除 Key 不删除画布；记得另行导出 ZIP 备份。

失败时：401 / 403 检查 Key 和权限；429 / 5xx 检查限流及任务记录。取消本机等待不等于取消远端视频任务；避免重复提交造成额外费用。钥匙串不可用时不会降级明文保存。AI 功能与隐私说明 →

17 / 遇到不支持或失败时

  • 按钮灰色：先确认已打开支持的 PDF。填写表单、度量、对比、整份 PDF 翻译、Office 完整转换、PDF 转 Office、印章等本来就尚未支持，详见清单。
  • 打不开：确认文件已完整下载到本机、密码有效；交互式表单控件会被拒绝。不要把原件反复覆盖或上传公开求助。
  • 搜索不到：检查文字层、复制权限及 OCR 边界；页面看起来有字不等于有可靠文字映射。
  • 内容编辑拒绝：常见原因是共享资源、复杂字体、变换或不支持的结构。保留草稿和原件，用自建最小示例复现；不要把批注覆盖当作成功编辑。
  • 本地组件缺失：使用完整安装包；原生版本无需单独安装 Python 或关闭系统保护。若完整包仍报缺失，记录版本与提示后反馈。
  • 输出效果异常：保留原件，不继续覆盖；对照重开的副本检查页面、文字和对象。技术测试覆盖不等于任意文档都已验收。
  • 反馈问题：在 GitHub Issues 提供 macOS 版本、App 版本、入口和最短复现步骤。优先附自建无隐私样本，不上传私人 PDF、API Key、账号或含敏感信息的截图。
