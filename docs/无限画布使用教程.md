# PDF Master 内置无限画布使用教程

适用版本：V0.1.7 / build 28（macOS）。本功能随软件打包，不加载无限画布网站，也不需要登录网站或创建 PDF Master 本机账户。

正式版与独立测试版的画布、最近文件及 Key 分开保存，不自动迁移。更新应用前请保存文档并正常退出，保留自己的 ZIP 备份。自行构建步骤见仓库 README。

## 1. 准备你自己的 DMX Key

在浏览器自行进入 [DMX 官网](https://www.dmxapi.cn/)，登录后进入“工作台 → API 令牌 → + 创建 API 密钥”，设置名称、有效期、额度和模型权限后复制 Key。建议给 PDF Master 单独建立有额度限制的令牌。

这是模型 API Key，不是管理接口的系统访问令牌。操作名称以 [DMX 官方令牌教程](https://doc.dmxapi.cn/lingpai.html) 为准。接口地址已内置为 `https://www.dmxapi.cn/v1`，不需要另填。软件不会代你注册、充值或购买额度。

## 2. 填入软件

1. 打开 PDF Master，点击左侧“无限画布”。
2. 点击画布上方“DMX Key 设置…”。
3. 粘贴 Key，点击“保存到钥匙串”。无需登录网站或本机账户。
4. 保存成功后原输入框会清空；不会显示或导出完整 Key。换 Key 时再次输入即可；“移除 Key”仅删除 Key，不删除画布。

内置画布的 Key 独立于旧版“账户与 AI 设置”中的账户 Key；不自动读取、迁移或共享旧账户的 Key。

## 3. 编辑与生成

画布自动恢复最近工作区。可使用原有节点、网格、工具栏、文字、图片、连线、手绘、素材和提示词库。文字整理、素材导入和本机存档无需网络。

选择节点或生成面板，填写提示词，选择模型、尺寸、数量等参数，再点击生成。首次连接 DMX 时，软件会询问是否允许本次画布会话发送提示词及你选择的参考素材；取消则不提交请求。批量生成的数量会影响费用，请先检查再确认。

图片示例：“一座木质湖畔小屋，清晨自然光，建筑摄影，16:9，无文字。”先选 1 张测试。实际模型可用性取决于你的 DMX 权限、余额及服务状态。

视频选择 Seedance 2.5，可文字生成或选择一张首帧图；检查时长、分辨率、声音和水印参数。多个参考图、尾帧、参考视频和参考音频暂不支持，软件会在提交前提示。成功提交后按已有任务 ID 查询，不自动重提；取消本机等待不代表远端任务已取消，也不保证免计费。

内置 AI 文本/图像/音频请求沿用原面板。独立网站的服务端 Agent、外部模型渠道、远程插件安装、云同步和本机公网素材托管没有随此版本打包，不应据此入口假定可用。

## 4. 保存与备份

画布、素材和生成记录保存在 PDF Master 的 WebKit 本机存储，固定本地源 `pdfmaster-canvas://workspace`。它与浏览器网站数据完全分开；不自动同步、不自动迁移网站画布。

通过画布菜单导出 ZIP，选择保存位置。需要恢复时用画布库的导入功能选择 ZIP。建议定期导出；不要把“清除本地数据”当普通退出操作。

导出使用原生保存窗口并保留文件名；单次导出上限 200 MB，较大的项目请分批导出节点或资产。

旧“无边记”及 `.pdfmasterboard` 保持原样；它与内置无限画布 ZIP 是两种不同格式，不能直接互换。当前打开的 PDF 不会被自动扫描或上传。

## 5. 常见问题

- 提示未设置 Key：点击顶部“DMX Key 设置…”，重新保存。不要在旧网站登录页或普通配置 JSON 中填 Key。
- HTTP 401 / 403：检查令牌是否有效、过期或缺少模型权限。HTTP 429 / 5xx：可能是限流或服务拥塞；先看 DMX 任务记录，尤其视频不要盲目重复提交。
- Keychain 不可用：检查 macOS 钥匙串访问权限；软件不会降级成明文保存。
- 离线时生成失败：编辑仍可用，模型生成必须联网且可能计费。
- 外部图片链接无法导入：先下载到本机再导入；内置版不使用网站代理。
- 从旧网站看不到原项目：两者存储独立；请先在旧网站手动导出，再在软件导入，软件不会偷偷读取网站账户或数据。
- 返回教程后如何继续：点击顶部“返回画布”；本次发送授权会重置，画布存档保留。

安全提醒：不要分享或截图完整 Key，不要提交到 Git。软件没有内置公共 Key；填写你自己的 Key 后，实际费用由你的 DMX 账户承担。

当前验证范围见 [兼容性与验证说明](../VERIFICATION.md)。未使用真实 Key 做付费生成验收；Windows 本轮未实现。公开源码不附画布上游项目演示图片/视频及第三方提示词 JSON 快照，请自行导入有权使用的素材。
