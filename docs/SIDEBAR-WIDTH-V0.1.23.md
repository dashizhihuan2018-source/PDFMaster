# V0.1.23 / build45 · Apple 原生左栏调宽

2026-10-27。此版本是 Swift / AppKit / PDFKit 原生版，不以 Rust 候选替换本机正式 App。

## 使用

拖动阅读器左栏右侧细分隔线。缩略图、目录、搜索、批注共用宽度，松手后写入本机偏好；隐藏再展开、正常退出后重开保留。方向键每次 8 点，Shift 加速至 32 点，Home / End 到两端，Esc 或窗口失焦取消未完成拖动。

常规宽度 176–480 点，至少为阅读区保留 200 点。窄窗口或 AI 面板打开时临时收窄，不覆盖保存的宽度；隐藏侧栏时没有残留占位。调整布局不修改 PDF，也不新增文档撤销记录。
