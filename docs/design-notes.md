# 官网设计说明

2026-10-26：检索 GitHub 产品官网与落地页项目，选用 [Magic UI](https://github.com/magicuidesign/magicui) 作为信息层级和交互节奏参考；同时查看 [Tailark Blocks](https://github.com/tailark/blocks) 与 [Cruip Landing Page](https://github.com/cruip/tailwind-landing-page-template)。星标会变化，热度不等于适合所有产品。

本页独立使用 HTML/CSS 实现，没有复制这些项目的源码、商标或宣传素材。采用宽留白、大字号标题、产品舞台与功能卡片结构；视觉为暖纸色、深蓝与朱红，标题使用思源宋体粗体。没有采用 Skyfall 网站的复制实现。

产品海报、视频与图标沿用本项目已获授权的原始素材，权利说明见 [素材清单](media/README.md)。思源宋体按 [SIL OFL](fonts/OFL.txt) 随站点分发。视频由用户主动播放；没有第三方统计脚本。手机布局和键盘入口分别验证，遵循减少动态效果的系统偏好。

功能页、教程和官网版本状态独立于软件包发布；待发布功能必须明确标记，不以页面上线代替应用验收。
