# V0.1.24 / build46：原生目录空白与行距

2026-10-27。本版是 Apple AppKit/PDFKit 原生版本，不是 Rust/Tauri 候选。

## 原因与修复

目录误用搜索结果的固定54点行高，单行标题下方出现大片空白；只有空格、换行或制表符的标题也被原样显示，没有可辨识标题。现在目录独立使用28点单行，悬停显示完整标题；显示投影折叠空白字符，空标题显示“未命名”。不改原PDF标题、目录树、目标或页码；搜索保持54点双行、批注保持44/60点。

现场当前文档能读取139项，窗口有标题，并非目录数据全部丢失。使用自建4页20项多层目录，在旧build45真实窗口复现过大间距和空白标题。本轮不把这项修复宣称为所有“整栏完全空白”的未知情形均已解决。

新增回归先失败：54点不满足28点、空白标题未回退；实现后相关27项通过。覆盖多层树、页码、受限/无目标、176/320/480点宽度、缩略图/批注/搜索/目录循环、刷新、关闭与替换文档、跳转及原始标题不变。
