# V0.1.27 / build49：阅读布局固定侧栏

2026-11-09，macOS 14+，Apple 芯片，开发预览。ad-hoc 签名，未获 Apple 公证。

## 功能与入口

阅读器左上角“布局选项”打开固定左栏，不再弹出小浮窗。单页、双页使用并排按钮与蓝色选中轮廓；双页下显示“单独显示首页”。再次点击布局入口恢复原侧栏，隐藏与重开、页面预览与布局之间切换仍复用已有侧栏宽度。显式进入大纲、缩略图或搜索时返回相应侧栏。

连续滚动保留在真实“显示 → 连续滚动”菜单；适合页面、适合宽度仍在显示菜单及缩放入口。只改变阅读布局，不保存或修改 PDF 内容。各文档保持独立阅读状态。

本次参考 PDF Expert 的可观察布局交互，自有代码实现；未分发其代码或资源，不宣称算法等价。没有新增垂直/水平分屏引擎，也不摆放不可用的分屏按钮。
