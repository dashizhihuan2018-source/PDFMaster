# V0.1.35 / build57：图片直接按原比例插入

修复图片被放进A4竖版页面的问题。默认每张图片按自身比例生成独立页面，横图横页、竖图竖页、方图方页，应用EXIF方向，无额外纸张白边、不裁切。插入已有PDF时保留原有页面，不强行统一页面尺寸。

默认“按图片比例”同时保留体积优化：大图的页面长边以阅读尺寸等比限制，最长720PDF点，按150DPI控制嵌入像素；小图不增加像素。页面比例按原始图片定义，不因缩略图整像素取整而产生边框。需要原分辨率可选“图片像素尺寸”；A4/Letter打印排版仅在主动选择时使用，不再是默认值。压缩有损，不承诺原图画质/HDR保持。

2026-11-12后台验证：横/竖/方图插入已有PDF后，保存重开仍为原图片页面比例，已有页面不变，批量插入可一次撤销；大图贴边角点、EXIF方向、透明PNG、小JPEG、原像素模式及体积边界回归通过。相关后台测试70项通过，当前release对象打包4项另重复验证。

原75张HEIC逐页比例与源图方向一致，合并保存重开75页、15,541,283字节（约15.5MB）；原图SHA-256不变。不同输入的体积和表现可能不同。未做前台目视、高清打印或其它Mac验收。

已安装V0.1.35/build57，版本/严格签名/主程序哈希回读一致；安装后不自动启动。Apple Silicon arm64、最低macOS14、ad-hoc签名未获Apple公证的预发布。源码和安装包不含用户图片、PDF、账号或私有分析材料。
