# V0.1.28 / build50：布局栏视觉细化

2026-11-09，macOS 14+、Apple 芯片。ad-hoc 签名，未获 Apple 公证。

## 本次变化

按 PDF Expert 本机可观察界面细化单页／双页区域：13点标题、11点分组标签、28点按钮、1点蓝色轮廓、3点圆角、灰色选中底和灰白图文。图标和文字整体居中，间距6点，不再贴边。图标为自有代码绘制的矢量线条，没有复制参考软件的图片或代码。

未保存自定义侧栏宽度时，布局栏默认240点；用户已经保存的宽度优先。返回普通侧栏恢复原宽度，不把临时默认值写入设置。176、240、480点内容边界有回归覆盖。单页、双页和“单独显示首页”继续共用原生阅读器状态；显示 → 连续滚动及适合页面入口保留。没有新增分屏引擎或不可用的占位按钮。

REA 静态解析核对了 singlePageView:、twoPagesView:、twoPagesViewWithCover: 等动作；界面观测用于视觉比例判断。静态动作名不能证明运行时内部算法，观测也不构成全界面逐像素一致的证明。本次仅修正布局栏，不宣称整个产品与第三方软件完全相同。

## 验证与边界

- 最终公开树回归：PaperDesk 611、PaperCore 275，共886项记录，884通过、2项私人样本跳过、0失败。
- 新增4项测试覆盖字体／几何、内容边界、240点默认及自定义宽度保留、明确sRGB绘制与无歧义辅助功能名称；相应旧行为先出现RED，再通过GREEN。15项布局／调宽定向测试通过；独立代码复审通过。
- 颜色测试最初重复转换了校准色，失败日志保留；最终在明确sRGB上下文读取原始RGBA字节，背景为40/40/44/255，不以放宽容差掩盖差异。
- 本机候选实测单页、双页、首页开关和条件显示；辅助功能不再把双页误报为“书签”。这不代表VoiceOver完整朗读、Tab焦点环、所有系统外观和字体、其他Mac或人工接受均已验收。
- 正式安装的版本、签名和哈希已回读；安装后的GUI复验因Mac锁屏尚未完成，不能用候选观察代替该项。
- 前端类型检查、生产构建、原生发行构建完成。保留既有体积／平台和部分测试约束诊断，不将警告当新增失败。
