01 / 阅读、搜索与资料导航

PDF 阅读与多标签

入口：主界面“打开文件”、拖入文件，或“文件 → 打开…”。新标签使用 ⌘T；打开后的 PDF 在顶部标签间切换。

结果：浏览 PDF、输入页码跳转，用缩略图和已有大纲定位页面；“显示”菜单提供单页、双页、封面布局、适合页面、适合宽度、实际大小及缩放。布局选项还可切换连续滚动。

受密码保护的文档需输入有效密码。含交互式表单控件的 PDF 当前会被拒绝打开，不承诺完整表单兼容。字体兼容修复只处理已识别的异常嵌入 CFF，不能修复任意坏字体；失败会提示并保留原件。

阅读操作步骤 →

文字搜索、大纲与最近记录

入口：“查找 → 查找”（⌘F），或侧栏搜索；“大纲”菜单可查看、添加当前页的顶层书签、重命名和删除顶层书签。主界面“最近 / 收藏”用于重新打开本机文件。

结果：逐项定位搜索结果，⌘G / ⇧⌘G 切换前后结果；书签跟随保存的 PDF。最近记录保存文件位置，不是文档备份；清除记录不删除原文件。

搜索依赖可提取文字，并尊重原始复制权限；图片扫描页需先 OCR。每次最多显示 1000 个结果，达到上限后请细化关键词。大纲编辑暂限顶层条目；文件移动后最近入口可能失效。

02 / 批注、绘图、签名与图章

部分支持 · 本机处理

高亮、文字、便笺、形状与手绘

入口：工作台“批注”，或“编辑 / 批注”菜单。提供高亮、下划线、删除线、文字批注、便笺、矩形、椭圆、直线、箭头、双向箭头和手绘。

结果：在页面上添加可选中、编辑或删除的 PDF 批注；所选批注可调整对应属性，手绘支持颜色和线宽。侧栏批注列表可导航、排序、复制摘要；文件菜单可导出 TXT、Markdown、HTML 批注摘要。

高亮等文字标记需先选中文字。新增文字是 FreeText 批注，不等于修改底层原文；也不是 Word 式自动排版。橡皮删除整条笔迹，不支持局部擦除。一般“绘图”是批注，不是 CAD 绘制或测量工具。

批注与手绘教程 →

图形签名 · 非数字证书

手写签名与“印章”的区别

入口：“填写和签名 → 签名”，或“编辑 → 图形签名…”。在弹窗绘制后插入页面；文字工具可添加普通文字批注。

结果：手写笔画作为图形批注加入 PDF，可保存和撤销。

不是数字证书签名，不提供证书身份验证、时间戳或法律效力保证。工具栏“印章”当前禁用，没有可用的盖章流程，也不提供电子公章或验章功能；不能把图形签名当作公章。查看操作与提醒 →

03 / PDF 内容编辑

“原文编辑”和“新增文字批注”是两条不同路径。原文编辑会重写支持的内容对象；复杂或无法可靠识别的内容会拒绝处理，不会悄悄改成盖白块。
有限兼容 · 原生编辑

原文文字与新增文字

入口：工作台“编辑 → 文本”。点击可识别原文就地修改；在空白处点击或拖出区域则新建文字批注。

结果：支持的原文单行可替换文本，并选择本机字体、字号、颜色；⌘↩ 完成、Esc 取消。新增文字可拖动、双击再编辑。

原文替换暂限单行，不自动重排段落或压缩文字挤入邻文。缺失字体可能替代；共享内容流、自定义简单字体编码和复杂结构可能拒绝，扫描图像不等于可编辑文字。失败草稿保留；OCR 不保证把扫描页变成可自由重排的文本。编辑教程 →

图像替换与真实链接

入口：“编辑 → 图像”点击支持的原图，选择 PNG / JPEG 替换；“编辑 → 链接”拖出区域添加链接，点击已有支持的链接可修改地址或删除。

结果：更新支持的嵌入图像对象或 PDF 链接对象，不是在页面上仅贴一个样子。

共享图像、复杂变换或不支持的对象会拒绝。链接编辑不会自动打开网址；保存后请检查地址与目标区域。不保证保留所有复杂裁切、遮罩或第三方特殊链接动作。

隐藏 PDF 内容：实际移除，而非盖黑块

入口：工具“隐藏 PDF 内容”，或“编辑 → 隐藏”，拖出目标区域并确认。

结果：对支持的页面内容重写，移除区域内文字以及相交的图像、矢量对象；应用内可撤销，需存储副本得到重写后的文件。

相交对象可能整件移除，复杂结构拒绝处理。应用撤销历史仍包含先前快照；这是有限结构支持，不是经过认证的全面脱敏方案，不保证清除元数据、附件等全部潜在信息。敏感文件必须独立检查导出副本的搜索、复制、附件及元数据，不能仅凭外观判断。安全使用步骤 →

04 / 页面管理与合并

部分支持

预览、排序、旋转、插入、复制、裁剪、删除与提取

入口：工作台页面管理、“页面”菜单、“文件 → 附加文件并合并…”和“文件 → 提取页面…”。“页面 → 页面预览”（⌘4）进入缩略图总览，按界面选择页面并执行操作。

结果：更改当前工作区页面顺序、方向或裁剪范围；插入空白页、附加 PDF、复制页面；按范围提取独立 PDF。主界面也可混合导入多份文件生成独立合并文档，来源不改。

范围按实际页序计数，例如 1-3,5；不能删除最后一页。裁剪改变可见边界，不等于删除被裁掉的底层内容。重排后请检查大纲和链接。工具条“粘贴”按钮目前禁用，不应把它作为通用跨软件页面粘贴承诺。受保护来源的提取可能拒绝，或要求明确确认移除保护。页面整理教程 →

05 / 本地导入、转换与导出

新建 PDF、图片与文字文件导入

入口：“文件 → 新建”（⌘N）或工具“空白 PDF”；主界面“打开文件 / 拖入文件”支持 PDF、图片、TXT、MD、RTF 与纯文字 DOCX。工具“图片转 PDF”有独立导入流程。

结果：把本机图片或文字内容生成 PDF；混合选择可汇成新的独立 PDF，来源文件不改动。

RTF / DOCX 是文字重排分页，不保留 Word 完整版式、图表和复杂对象；这不代表工具箱的“Word 转 PDF”已实现。MD 按文字导入，不承诺完整 Markdown 排版。其他格式请先用原软件导出 PDF。导入教程 →

PDF 转图片、文字与批注摘要

入口：工具“PDF 转图片”；文件菜单“导出纯文本…”以及三种“导出批注摘要…”；“文件 → 打印…”调用系统打印。

结果：按页码范围输出 PNG / JPEG，可选 72、144、300 DPI；输出到新文件夹，不覆盖已有文件夹。文字导出为 TXT；批注摘要可选 TXT、Markdown、HTML。

图片导出是页面栅格图，失去可搜索文字和可编辑对象；高 DPI 更占空间。纯文本不保留版式，依赖复制权限和文字层。摘要只反映可读取的批注信息，不代替整份 PDF。PDF 转 Word / Excel / PowerPoint 暂不支持。导出教程 →

06 / 压缩、OCR 与页码

压缩 PDF

入口：工具“压缩 PDF”或“文件 → 压缩文件大小…”。

结果：“更小文件 / 均衡压缩 / 高清晰度”分别计算实际输出大小；还可勾选“仅无损优化（不降低画质）”。完成后选择“另存为压缩副本…”，原件不覆盖。

有损档会降低支持的图像质量或分辨率；不是整页统一截图，但照片、细线和扫描小字仍可能变差。已优化文档不保证再缩小；无损优化也可能没有收益。预览数字是已完成结果，编辑后旧快照结果会失效。压缩教程 →

识别文本：简体中文 / 英文

入口：工作台“扫描和 OCR”，或工具“识别文本”。

结果：本机识别清晰、水平的扫描页，跳过已有文字的页；识别结果可在本机检索，处理后需保存副本。

暂不支持旋转或裁剪页；不是表格还原、手写识别或复杂版式编辑。OCR 会出错，请核对人名、数字及符号。跨阅读器的通用文字提取兼容性尚未通过，不能承诺导出后在所有阅读器均能正确搜索复制。OCR 教程 →

添加页码

入口：工具“页码”，输入起始数字、前缀、后缀，可选放在页面顶部。

结果：在所有页面顶部或底部居中添加新的页码，可撤销，保存副本后保留。

起始值必须为非负整数；只支持未旋转、未裁剪页面，不替换已有页码，可能与原内容重叠。页码教程 →

07 / 保存、撤销与密码保护

选择合适的保存方式

入口：“文件 → 保存”（⌘S）、“另存为…”（⇧⌘S）、“存储副本…”、“存储打平副本…”和“存储密码保护副本…”；“编辑 → 撤销 / 重做”（⌘Z / ⇧⌘Z）。

结果：保存当前修改，或输出独立副本；打平副本固定批注外观、不再保留原有的批注编辑方式；未加密来源可以创建密码保护副本。

保存到原文件会覆盖它，建议首次编辑先存副本。已有加密 PDF 的重新导出不能可靠保留原始底层保护时会拒绝，而不自动退回明文。签名 PDF 的内容重写也受安全限制；不要依赖修改后保留数字签名有效性。撤销历史不等于长期备份，外部导出和 AI 请求也不能通过撤销收回。保存与恢复教程 →

08 / 无边记与无限画布，不是同一个存档

无边记：本地资料画布

入口：主界面侧栏“无边记 → 新建无边记 / 打开无边记…”，或“文件 → 新建无边记”。

结果：使用选择、手掌、便笺、文本、矩形、圆形、连线、手绘、图片、PDF 卡片组织资料；支持缩放和平移、撤销重做。保存为 .pdfmasterboard；导出 PDF / PNG。

PDF 卡片嵌入副本；双击打开的是独立 PDF，编辑不会反写原件或画布卡片。PDF / PNG 导出是展示交付，不是可继续编辑的画布存档；保留 .pdfmasterboard 才能继续编辑。AI创作属于可选联网功能。无边记教程 →

无限画布：随 App 内置的节点工作区

入口：主界面侧栏“无限画布”。上方有“返回画布 / DMX Key 设置… / 使用教程”。

结果：离线整理节点、文字、图片、连线、手绘、素材和提示词；画布及素材保存在这台 Mac 的 WebKit 存储，通过画布菜单导出 ZIP 备份、从画布库导入 ZIP 恢复。

不用网站登录，但本地存储不是云备份；不能把清理本地数据当作退出登录。无限画布 ZIP 与无边记 .pdfmasterboard 是不同格式，不自动互转。AI 图片 / 视频生成需自备 DMX Key 并联网，示例或展示素材不代表实时生成，也不保证服务商模型随时可用。无限画布教程 →

09 / 可选 AI：软件免费，服务商独立计费

PDF Copilot 与账户设置

入口：工具“PDF Copilot”或工作台 Copilot 入口；“AI Key 设置…”进入本机账户和服务商 Key 管理。支持 DMX、DeepSeek、Agnes 等对应的文字服务。

结果：根据可复制文字进行总结、提取要点、提问、解释、文字翻译、测验或批注摘要。默认发送当前页；可切换全文，最多 4 万字、超限截断，并发送本轮对话。回答和引用须核对原文。

这是文字助手，不是整份 PDF 版式翻译或原文件自动改写。必须勾选发送授权并点击生成才发送；不上传 PDF 二进制或页面图片。加密或限制复制的 PDF 不提取发送。软件不附赠服务商额度，实际费用、模型权限及可用性由服务商决定；停止本机请求不保证远端停止计费。

两套 Key 入口与隐私

PDF Copilot / 本机 AI 创作使用当前本机账户对应的 Key，存入 macOS 钥匙串；本机账户不是云账号，阅读批注无需登录。内置“无限画布”的 DMX Key 独立保存，无需本机账户，不自动迁移或共享。

无限画布生成会发送提示词及你选择的参考素材，首次发送需确认会话授权；改 Key、刷新或退出后重新确认。视频任务可能继续在远端运行，查询失败时请先检查任务记录，勿反复提交。不要在共享 PDF、画布、导出 ZIP、截图或反馈中放 API Key。AI 配置与费用教程 →

10 / 暂不支持，不作为可用功能宣传

工具卡片 / 禁用入口

以下项目即使出现在工具列表中，目前也不能按名称完成操作：

  • 填写交互式表单、页面重设大小、对比 PDF、度量。
  • 整份 PDF 翻译、红线。Copilot 的文字翻译不等于整份 PDF 翻译。
  • Word 转 PDF、表转 PDF、其他文件转 PDF 工具卡片。主界面的有限文字导入是单独能力，不是完整 Office 转换。
  • PDF 转 Word、PDF 转 Excel、PDF 转 PowerPoint。
  • 批注工具条“印章”、页面工具条“粘贴”等禁用按钮。

当前是有明确兼容边界的开发预览，不保证任意 PDF、字体、复杂对象或大型文件都能处理。失败时以界面提示为准；先保存副本，再对输出做独立检查。
