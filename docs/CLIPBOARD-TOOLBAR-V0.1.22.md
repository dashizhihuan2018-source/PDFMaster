# V0.1.22 / build44 · 页面图片互通与上下文工具栏

## 复制与粘贴

- 阅读区没有文字或批注选择时，⌘C复制当前页；选中文字时仍使用原生文字复制，选中批注时优先复制可编辑批注对象。
- 页面缩略图、页面管理“复制页面”和阅读区复制共用同一剪贴板路径。显式提供PNG、TIFF、标准PDF与应用内页面PDF，不用只支持PDF解码的接收端假设。
- 多页按选中顺序合成长图，保留每页批注、裁剪与旋转；应用内粘贴仍保留全部独立PDF页面。图片最大8192边、16,777,216像素，多页过长会整体降低分辨率；不把合成长图声称原始矢量PDF。
- Esc现在同时清理内部批注选择，避免选框消失后⌘C仍复制不可见的旧批注。无对象剪切显示选择提示，不把一切无选择都误报为权限限制。
- 无效PDF在清空剪贴板之前拒绝，保留原剪贴板。PDF原始复制/装配权限不绕过，文字编辑框继续使用自己的复制和撤销。

显式图片格式针对微信等图片接收端。剪贴板格式、像素与应用内往返有独立测试；未进行微信消息发送，不把AppKit测试等同微信接收端验收。实际接收端状态以Release最终说明为准。

## 异常空白

选中图形/墨迹时，原来无主模式却仍预留34点的空工具行；取消选择还可能残留84点空面板。现在从真实可见控件计算高度：仅属性50点，有真实工具行+属性84点，无控件0点。保留文字编辑的34点样式行，不用覆盖或负间距遮挡内容。

先复现固定空行、缺图片类型、阅读区无选择不能复制及Esc残留的失败测试，再实现。回归覆盖不同窗口大小、显式PNG/TIFF真实批注像素、多页顺序/旋转、内部PDF往返、文字/批注优先级及无效输入保护。完整测试、真实候选、安装身份和公开下载分别记录，不代表用户接受或所有接收端兼容。

本版保留前版批注紧凑/日期和原生内容引擎，保留并行Rust候选，不将其替代已验证的原生桌面包。无用户PDF、截图、聊天、凭据或个人设置纳入公有载荷。
