# V0.1.34 / build56：按页面所需像素输出

上一版修复了累计像素误限和JPEG重复编码，但A4纸面仍保留手机照片的全部像素，75张HEIC的转换数据合计约170.6MB。本版在A4/Letter模式下按实际绘制区域使用150DPI均衡输出，只缩小超出需要的像素，不给小图额外增加像素；边距、纸张和顺序保持。

需要保留全部像素时，仍可选“图片像素尺寸”：维持一像素对应一PDF点，JPEG保留原压缩流，文件和物理页面可能较大。固定纸张的150DPI不是原图品质，也不是高清打印/大幅放大档；缩小和照片JPEG编码有损，原始图片不会改动。HEIC/HEIF沿用0.7质量JPEG转码。透明PNG/TIFF保留透明处理。

2026-11-12后台验证：同一75张HEIC的转换数据合计13,486,899字节，比上一版170,613,114字节减少约92.1%；实际合并、保存并重开为75页、13,145,181字节（约13.1MB）。原图片SHA-256全部保持。该样本探针约5秒、峰值RSS约272MB，不是所有图片/设备的性能承诺或硬内存上限。

66项相关后台测试通过：实际PDF图像XObject尺寸满足页面150DPI、缩小后的EXIF1–8没有再次旋转/镜像、透明PNG在原尺寸和缩小后仍对白底正确合成；小JPEG/原像素模式、批量导入、合并保存重开和失败不发布均回归。另对当前release对象的4项打包检查通过。真实前台操作、高清打印和其它Mac未验收。

已安装V0.1.34/build56，版本、严格签名和主程序哈希回读一致，安装后不自动启动。arm64、最低macOS14、ad-hoc签名、未获Apple公证的预发布。保留原有文件/页数/像素/字节上限，不保证任意照片输出都小于来源总大小。
