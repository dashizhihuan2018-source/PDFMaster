# V0.1.25 / build47：多窗口与显式水印移除

## 多窗口

- 文件 → 新建窗口（⌘⌥N），各窗口独立阅读与编辑。
- PDF 标签右键 → 移到新窗口；也可拖出标签栏后松开。拖动时 Escape 取消，不创建窗口。
- 转移保留同一文档、未保存编辑、页位、缩放与撤销历史。关闭检查本窗口，退出检查全部窗口。
- 原有“新建无边记”快捷键 ⌘⇧N 保留。

## 去水印

入口为文件 → 删除水印，以及当前 PDF 的编辑工具条 → 删除水印。按本机 WPS 普通命令的 REA 静态证据修订交互：在当前 PDF 中检测水印，简短确认后原位异步处理；无可直接移除的水印则明确提示。不新增首页卡片、独立预览面板或批量导出流程。本机候选已观察确认、取消保留原文、删除后状态及撤销恢复；WPS 本体的完整菜单→删除运行时链仍未完成，不称像素一致或全部行为等价。

支持的保守子集：显式 `/Subtype /Watermark` 批注，以及单内容流中可独立移除的 `/Artifact`、`/Subtype /Watermark` 标记。按页处理共享流，保留普通正文和批注；不凭透明度、颜色或重复性猜测删除。

不支持：已烘焙进扫描图片的水印、未标记的普通文字/图片、复杂表单或多内容流等。加密、签名、主动内容/图层、不支持的旋转/裁剪等结构保守拒绝。不能识别时明确提示，不栅格化、不遮白，不宣称等同 WPS 全部去水印或 AI 服务。

只在本机处理，不上传 PDF。目标契约为当前文档一个可撤销编辑，保留现有未保存内容；取消、失败和过期结果不写回，成功后沿用 PDF Master 正常保存命令，不自动覆盖磁盘文件。这是 PDF Master 自身安全契约，不代表 WPS 自动保存/撤销行为已经证实。

## 账号与 AI

沿用设备本地账号、记住登录和独立 Keychain 存储。默认文本服务商为 Agnes，AI 发送仍需勾选授权；未调用真实 AI 不等于服务可用性已验收。公开源码和安装包不附带设备的会话、授权 Key 或私人 PDF。“本地账号”不赋予 macOS 管理员权限。

## 构建和验收边界

Apple Silicon arm64，构建目标 macOS 14+，qpdf 随包提供，无需另装 Python/Homebrew。ad-hoc 签名，未获 Apple 公证；不是 App Store 发行或所有 Mac 的兼容承诺。完整源码、第三方说明与构建脚本随本标签公开，设备配置不进入源码附件。

使用自建样本进行自动测试及候选 App 验证；测试清单与最终交付身份见本版验证回执。自动化通过不等于用户人工接受。
