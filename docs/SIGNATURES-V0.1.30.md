# V0.1.30 / build52：右侧签名库与创建预览

## 使用

“填写和签名 → 签名”或“编辑 → 图形签名…”打开文档右侧签名库，不再弹出独立的“我的签名”窗口。

- 点击顶部＋添加签名；图片模式选择或拖放PNG，检查预览后点“创建”。选择文件本身不会保存历史；取消或关闭编辑器丢弃草稿。
- 绘制模式可手写，创建后作为透明图片签名保存在本机历史。图形签名统一使用自包含PDF Stamp，不是数字证书签名。
- 历史按保存顺序显示；点击签名后在页面点击或拖框等比放置，Esc取消放置。添加后仍需正常保存PDF。
- 选择历史项后按Delete，或在该项右键点“删除”。没有二次确认，仅删除签名库副本，不删除原始PNG，不影响已签入PDF的副本。
- 相同规范化PNG去重，重启后历史仍可复用；同一配置的文档标签和窗口共享本机库。不会上传签名图片。

## 兼容与限制

单帧PNG最多8MiB/4,000,000像素；库最多100项/总资产128MiB，达到限额不自动淘汰。原有透明度及比例保留，不自动去白底。预览采用文件字节快照，确认前源文件发生变化不会替换已预览草稿。

坏图/缺失图仍可从历史删除；损坏索引、符号链接和特殊文件保守拒绝，不静默覆盖。已有PDF签名是独立数据，不依赖签名库原文件。

这一版落实已确认的原版行为结构，但不是完整或逐像素复刻完成：未实现背景透明度调节、文字/摄像头签名提供器、历史编辑及拖动重排，不用占位控件冒充。一般印章、电子公章、证书签章和验章不在范围内。不验证签署人身份，不提供可信时间戳或法律效力保证。

## 验证边界

默认自动化验证仅在后台执行，不启动候选App、不显示测试窗口、不抢占前台焦点；依赖前台激活的用例单独显式开启，不把跳过计为通过。原生行为测试、安装身份回读、安装包与源码校验分别记录；本版未继续进行前台GUI验收，本机通过不代表其他Mac、完整VoiceOver或所有系统功能验收。100张大图历史尚未压力实测。

2026-11-10最终后台全量原生测试935项：905通过、30明确跳过、0失败；其中28项需要前台会话，2项为私有样本opt-in。后台入口/守卫脚本测试11项通过。App安装身份为V0.1.30/build52，strict/deep签名及主程序SHA-256回读一致；安装后未自动启动。桌面实测与其他设备验收仍未完成。

最终包为Apple Silicon arm64、macOS14及以上、ad-hoc签名，未获Apple公证。保留原生内容与字体引擎及随包qpdf，无需外置Python/Homebrew；复杂PDF仍有保守拒绝边界。本项目与Readdle无官方关系，原版派生代码/资源、用户签名和私有测试资料不随源码或安装包公开。
