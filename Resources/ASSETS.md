# 品牌与工具图标

PDF Master 采用独立生成的品牌与工具图形，统一用于应用界面和产品识别。

- `PDFMaster.icns` 与 `Branding/PDFMaster.png`：折纸 M/PDF 品牌图形，由 imagegen 生成；ICNS 为同一原图的尺寸转换。
- `ToolIcons/*.png`：28 张独立生成的透明底彩色轮廓图标。
- `ToolSkins/art-minimal/*.png`：28 张独立生成的透明底极简几何图标。
